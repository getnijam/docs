# Nijam Docs

The documentation site for [Nijam](https://www.nijam.dev) — test analytics for Playwright. Built with
[Starlight](https://starlight.astro.build) (Astro). Hosted at **docs.nijam.dev**.

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
```

| Command           | Action                                             |
| ----------------- | -------------------------------------------------- |
| `npm run dev`     | Start the dev server with hot reload               |
| `npm run build`   | Build the static site to `./dist/`                 |
| `npm run preview` | Preview the production build locally               |

## Content & routing

All docs live in `src/content/docs/`. **The folder structure is the routing** — a file's path is its URL,
and its top-level folder is its sidebar group:

```
src/content/docs/
  index.mdx                  -> /                (home / splash)
  getting-started/
    introduction.md          -> /getting-started/introduction
    quickstart.mdx           -> /getting-started/quickstart
  concepts/                  -> "Core Concepts" group
  reporter/                  -> "The Reporter" group
  billing/                   -> "Billing" group
  reference/                 -> "Reference" group
```

### Add a page

1. Drop a `.md` (or `.mdx`, if you need components) file into one of the folders.
2. Give it frontmatter:

   ```md
   ---
   title: My new page
   description: One-line summary for SEO and search.
   sidebar:
     order: 3        # position within its sidebar group (lower = higher)
   ---
   ```

3. That's it — the sidebar is **autogenerated per folder** (see `astro.config.mjs`), so the page appears
   automatically. No config edit needed.

### Add a sidebar group

Create a new folder under `src/content/docs/`, then add one line to `sidebar` in `astro.config.mjs`:

```js
{ label: 'My Group', items: [{ autogenerate: { directory: 'my-folder' } }] }
```

### Use `.md` vs `.mdx`

Plain prose and code blocks → `.md`. If you want components (tabbed code, steps, callouts) use `.mdx` and
import them, e.g. `import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';`.

> ⚠️ In `.mdx`, keep a blank line between a JSX tag and a fenced code block — `<TabItem>` and a ` ``` `
> fence must not share a line, or the build fails.

## Search

Full-text search is built in via [Pagefind](https://pagefind.app/) — it's indexed at build time, runs
entirely client-side, and needs no external service or config.

## Deploy to docs.nijam.dev (Vercel)

This is a static site, so deploy it as its own Vercel project (separate from `web-app`):

1. Push this folder to a Git repo (e.g. `getnijam/docs`).
2. In Vercel, **Import** that repo. Vercel auto-detects Astro — no build config needed
   (build `astro build`, output `dist/`).
3. Add the domain **docs.nijam.dev** in the project's Domains settings and point a `docs` CNAME at the
   value Vercel gives you.
4. Every push to `main` rebuilds and redeploys.

If the canonical host ever changes, update `site` in `astro.config.mjs`.
